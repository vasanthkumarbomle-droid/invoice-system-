# LedgerFlow — Invoice & Quotation Generation System

LedgerFlow is a React and Vite billing application backed by Supabase.

## Features

- Dashboard with invoice, payment, and outstanding-balance summaries
- Client and product management
- Invoice creation, editing, preview, printing, and HTML export
- Quotation creation, status tracking, and conversion to invoices
- Payment recording and balance tracking
- Financial reports with date filters and CSV export
- GST breakdowns
- Company settings saved to Supabase
- Barcode/SKU product lookup and scanning

## Technology

- React
- Vite
- Supabase Authentication and PostgreSQL
- Recharts
- html5-qrcode
